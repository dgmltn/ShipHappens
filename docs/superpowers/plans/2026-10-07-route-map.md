# Route Map Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the detail screen's decorative map placeholder with an offline, stylized map of the parcel's scanned stops, each tappable to show what happened there.

**Architecture:** A new KMP module `:geo` owns place normalization, an offline bundled US-places geocoder plus a platform geocoder for misses, route building, and projection math — all pure and JVM-testable. `:data` adds a Room geocache table (DB v4) and a `GeoRepository` that resolves places lazily while the detail screen is open. `:ui` maps the route into `DetailUiState.route` and draws it with a Compose `Canvas` inside the existing 152dp card.

**Tech Stack:** Kotlin Multiplatform (android, iosArm64, iosSimulatorArm64, jvm), Compose Multiplatform 1.11.1 (`components.resources` for the binary assets), Room 3 (`androidx.room3`), Koin, kotlinx.coroutines, Python 3 for the one-off asset script.

**Spec:** `docs/superpowers/specs/2026-10-07-route-map-design.md`

## Global Constraints

- Platforms: every `expect` gets Android **and** iOS actuals (plus jvm where the module has a jvm target). No dormant TODO actuals.
- No network at build time; generated assets are committed. Assets are public-domain only (Census Gazetteer, Natural Earth).
- Geocoding never runs during background refresh — only from the detail ViewModel's scope.
- Platform lookups: serial, at most **10 per `GeoRepository.observe` collection**.
- Cached misses retry after **30 days**; `Unavailable` results are never cached.
- Map card keeps its existing size/clip/background/border: `height(152.dp)`, `RoundedCornerShape(18.dp)`, `Color(0xFFEEECE6)`, `ShipColors.hairline` border, bottom-left location label.
- Bounds: 15% padding per side, minimum span **3°** per axis, expanded to the card's aspect ratio. Antimeridian shift when longitude span > 180°.
- Tap hit radius **24.dp**. Callout shows at most 4 events then "+N more".
- Room: version 3 → 4 via specless `AutoMigration(from = 3, to = 4)`; export `data/schemas/.../4.json`.
- Kotlin/Native: avoid `firstNotNullOfOrNull`/`filterIsInstance`/`any { it is T }` over sealed-interface lists in hot paths (known K/N 2.4.0 miscompile — see `WebViewBasedSource.kt`); plain `for` loops are fine.
- `Dispatchers.IO` is internal on Kotlin/Native — use `Dispatchers.Default` in common/iOS code.
- ViewModel tests over Room flows use the existing `awaitState` real-time pattern in `ui/src/androidHostTest/.../DetailViewModelTest.kt`; never `advanceUntilIdle(); state.value`.
- Commits: subject starts with a bracketed one-word tag (`[geo]`, `[data]`, `[detail]`), describes the problem not the mechanics, **no** Co-Authored-By trailer or AI footer. Work on branch `feat/route-map`; never push.
- Comments: follow the `comment-preferences` skill (explain why, not what; no ticket/task references).
- Never commit `gradle/gradle-daemon-jvm.properties` if a Gradle run generates it.

## Review Focus

1. **Carrier location shapes the table can't match** — "SOUTH SAN FRANCISCO CA 94080 US", "Memphis, TN, United States", "CARLSBAD, CA, US", lowercase/extra spaces. Expect all to normalize to `CITY, ST`. Pinned in Task 1 tests.
2. **Gazetteer names carry LSAD suffixes** ("Sacramento city", "Foster City city", "Ontario CDP") — the script must strip exactly one trailing suffix word so "FOSTER CITY, CA" still matches. Pinned in Task 3 smoke test (`FOSTER CITY, CA`, `SACRAMENTO, CA`).
3. **Offline first open** — platform geocoder throws; route must still draw bundled hits and retry the rest next open (no miss cached). Pinned in Task 7 `unavailable_is_not_cached`.
4. **Route re-emits while the user has a stop selected** — selection must reset if the stop list changes, not crash on a stale index. Pinned in Task 10 `selection_resets_when_stops_change`.
5. **Pacific-crossing routes** (e.g. Shenzhen → Los Angeles) — must not draw across the whole world. Pinned in Task 6 `antimeridian_route_is_shifted`.

```kotlin
package com.dgmltn.shiphappens.geo

data class LatLng(val lat: Double, val lng: Double) {
    val isValid: Boolean
        get() = lat.isFinite() && lng.isFinite() && lat in -90.0..90.0 && lng in -180.0..180.0
}

sealed interface GeoResult {
    data class Found(val at: LatLng) : GeoResult
    /** The geocoder answered and has no such place. Safe to remember. */
    data object NotFound : GeoResult
    /** The geocoder couldn't answer (offline, throttled, absent). Worth asking again later. */
    data object Unavailable : GeoResult
}

/** Looks up a key already produced by [PlaceKey.normalize]. */
fun interface Geocoder {
    suspend fun lookup(key: String): GeoResult
}

object UnavailableGeocoder : Geocoder {
    override suspend fun lookup(key: String): GeoResult = GeoResult.Unavailable
}
```

```kotlin
// geo/src/commonMain/kotlin/com/dgmltn/shiphappens/geo/PlaceKey.kt
package com.dgmltn.shiphappens.geo

/**
 * Carriers spell the same place many ways ("SOUTH SAN FRANCISCO CA 94080 US",
 * "South San Francisco, CA"). The bundled table and the geocache are both keyed by the one
 * canonical form this produces: "CITY, ST" for US places, "CITY, CC" otherwise.
 */
object PlaceKey {
    private val ZIP = Regex("""\b\d{5}(-\d{4})?\b""")
    private val US_SUFFIX = Regex("""(,\s*|\s+)(US|USA|UNITED STATES|UNITED STATES OF AMERICA)$""")
    private val TRAILING_STATE = Regex("""^(.*\S)\s+([A-Z]{2})$""")

    fun normalize(raw: String?): String? {
        if (raw == null) return null
        var s = raw.uppercase().replace(ZIP, " ")
        s = s.split(',').map { it.trim().replace(Regex("""\s+"""), " ") }.filter { it.isNotEmpty() }.joinToString(", ")
        s = s.replace(US_SUFFIX, "").trim().trimEnd(',').trim()
        if (s.isEmpty()) return null
        val parts = s.split(", ").toMutableList()
        if (parts.size == 1) {
            val m = TRAILING_STATE.matchEntire(parts[0])
            if (m != null && m.groupValues[2] in US_STATES.values) {
                parts[0] = m.groupValues[1]; parts.add(m.groupValues[2])
            }
        }
        if (parts.size >= 2) {
            val last = parts.last()
            US_STATES[last]?.let { parts[parts.lastIndex] = it }
        }
        return parts.joinToString(", ").takeIf { it.any(Char::isLetter) }
    }

    private val US_STATES: Map<String, String> = mapOf(
        "ALABAMA" to "AL", "ALASKA" to "AK", "ARIZONA" to "AZ", "ARKANSAS" to "AR", "CALIFORNIA" to "CA",
        "COLORADO" to "CO", "CONNECTICUT" to "CT", "DELAWARE" to "DE", "DISTRICT OF COLUMBIA" to "DC",
        "FLORIDA" to "FL", "GEORGIA" to "GA", "HAWAII" to "HI", "IDAHO" to "ID", "ILLINOIS" to "IL",
        "INDIANA" to "IN", "IOWA" to "IA", "KANSAS" to "KS", "KENTUCKY" to "KY", "LOUISIANA" to "LA",

        "NEBRASKA" to "NE", "NEVADA" to "NV", "NEW HAMPSHIRE" to "NH", "NEW JERSEY" to "NJ",
```

  - Decoders throw `IllegalArgumentException` on bad magic/version/truncation.

```kotlin
package com.dgmltn.shiphappens.geo

internal class BigEndianWriter {
    private val out = ArrayList<Byte>()
    fun bytes(b: ByteArray) { b.forEach { out.add(it) } }
    fun int(v: Int) { for (s in intArrayOf(24, 16, 8, 0)) out.add((v ushr s).toByte()) }
    fun short(v: Int) { out.add((v ushr 8).toByte()); out.add(v.toByte()) }
    fun float(v: Float) = int(v.toRawBits())
    fun toByteArray() = out.toByteArray()
}

internal fun encodePlaces(places: Map<String, LatLng>): ByteArray = BigEndianWriter().apply {
    bytes("SHPL".encodeToByteArray()); int(1); int(places.size)
    places.entries.sortedWith { a, b -> compareBytes(a.key.encodeToByteArray(), b.key.encodeToByteArray()) }.forEach { (k, v) ->
        val kb = k.encodeToByteArray(); short(kb.size); bytes(kb); float(v.lat.toFloat()); float(v.lng.toFloat())
    }
}.toByteArray()

internal fun encodeLand(rings: List<List<Pair<Float, Float>>>): ByteArray = BigEndianWriter().apply {
    bytes("SHLD".encodeToByteArray()); int(1); int(rings.size)
    rings.forEach { ring -> int(ring.size); ring.forEach { (lng, lat) -> float(lng); float(lat) } }
}.toByteArray()
```

```kotlin
// geo/src/commonMain/kotlin/com/dgmltn/shiphappens/geo/BinaryReader.kt
package com.dgmltn.shiphappens.geo

internal class BinaryReader(private val b: ByteArray) {
    var pos = 0
        private set

    private fun need(n: Int) = require(pos + n <= b.size) { "truncated asset at $pos (+$n of ${b.size})" }

    fun magic(expected: String) {
        need(expected.length)
        val got = b.decodeToString(pos, pos + expected.length)
        require(got == expected) { "bad magic: $got" }
        pos += expected.length
    }

    fun int(): Int {
        need(4)
        val v = ((b[pos].toInt() and 0xFF) shl 24) or ((b[pos + 1].toInt() and 0xFF) shl 16) or
            ((b[pos + 2].toInt() and 0xFF) shl 8) or (b[pos + 3].toInt() and 0xFF)
        pos += 4
        return v
    }

    fun ushort(): Int {
        need(2)
        val v = ((b[pos].toInt() and 0xFF) shl 8) or (b[pos + 1].toInt() and 0xFF)
        pos += 2
        return v
    }

    fun float(): Float = Float.fromBits(int())

    fun utf8(len: Int): String {
        need(len)
        return b.decodeToString(pos, pos + len).also { pos += len }
    }
}

internal fun compareBytes(a: ByteArray, b: ByteArray): Int {
    val n = minOf(a.size, b.size)
    for (i in 0 until n) {
        val d = (a[i].toInt() and 0xFF) - (b[i].toInt() and 0xFF)
        if (d != 0) return d
    }
    return a.size - b.size
}
```

```kotlin
// geo/src/commonMain/kotlin/com/dgmltn/shiphappens/geo/PlacesTable.kt
package com.dgmltn.shiphappens.geo

/** Sorted, immutable key → coordinate table decoded from `places.bin`. */
class PlacesTable private constructor(
    private val keys: Array<ByteArray>,
    private val coords: FloatArray,  // lat0, lng0, lat1, lng1, …
) {
    val size: Int get() = keys.size

    fun lookup(key: String): LatLng? {
        val needle = key.encodeToByteArray()
        var lo = 0
        var hi = keys.size - 1
        while (lo <= hi) {
            val mid = (lo + hi) ushr 1
            val c = compareBytes(keys[mid], needle)
            when {
                c < 0 -> lo = mid + 1
                c > 0 -> hi = mid - 1
                else -> return LatLng(coords[mid * 2].toDouble(), coords[mid * 2 + 1].toDouble())
            }
        }
        return null
    }

    companion object {
        val EMPTY = PlacesTable(emptyArray(), FloatArray(0))

        fun decode(bytes: ByteArray): PlacesTable {
            val r = BinaryReader(bytes)
            r.magic("SHPL")
            require(r.int() == 1) { "unsupported places version" }
            val count = r.int()
            require(count >= 0) { "negative count" }
            val keys = arrayOfNulls<ByteArray>(count)
            val coords = FloatArray(count * 2)
            for (i in 0 until count) {
                keys[i] = r.utf8(r.ushort()).encodeToByteArray()
                coords[i * 2] = r.float()
                coords[i * 2 + 1] = r.float()
            }
            @Suppress("UNCHECKED_CAST")
            return PlacesTable(keys as Array<ByteArray>, coords)
        }
    }
```

```kotlin
/** Land polygons as interleaved `[lng, lat, …]` rings, decoded from `land110m.bin`. */
class LandOutline(val rings: List<FloatArray>) {
    companion object {
        val EMPTY = LandOutline(emptyList())

        fun decode(bytes: ByteArray): LandOutline {
            val r = BinaryReader(bytes)
            r.magic("SHLD")
            require(r.int() == 1) { "unsupported land version" }
            val ringCount = r.int()
            require(ringCount >= 0) { "negative ring count" }
            val rings = ArrayList<FloatArray>(ringCount)
            repeat(ringCount) {
                val n = r.int()
                require(n >= 0) { "negative point count" }
                rings += FloatArray(n * 2) { r.float() }
            }
            return LandOutline(rings)
        }
    }
}
```

```kotlin
package com.dgmltn.shiphappens.geo

import kotlinx.coroutines.sync.Mutex
import kotlinx.coroutines.sync.withLock

/**
 * The table is ~400KB, so it's read on first use rather than at startup. A broken or missing
 * asset degrades to "knows nothing" — every place then falls through to the platform geocoder
 * instead of taking the detail screen down.
 */
class BundledGeocoder(private val load: suspend () -> ByteArray) : Geocoder {
    private val mutex = Mutex()
    private var table: PlacesTable? = null

    override suspend fun lookup(key: String): GeoResult {
        val t = mutex.withLock {
            table ?: runCatching { PlacesTable.decode(load()) }
                .getOrElse { PlacesTable.EMPTY }
                .also { table = it }
        }
        return t.lookup(key)?.let { GeoResult.Found(it) } ?: GeoResult.NotFound
    }
}
```

```python
#!/usr/bin/env python3
"""
One-off generator for :geo's bundled assets. Run by hand; Gradle never runs it.

Sources (both public domain):
  - US Census Bureau Gazetteer, national places file (2024 vintage):
    https://www2.census.gov/geo/docs/maps-data/data/gazetteer/2024_Gazetteer/2024_Gaz_place_national.zip
  - Natural Earth 1:110m physical land:
    https://raw.githubusercontent.com/nvkelso/natural-earth-vector/master/geojson/ne_110m_land.geojson

Usage: python3 -I scripts/build-geo-assets.py <scratch-dir>
Writes geo/src/commonMain/composeResources/files/{places.bin,land110m.bin}.
"""
import io, json, os, re, struct, sys, urllib.request, zipfile

GAZ_URL = "https://www2.census.gov/geo/docs/maps-data/data/gazetteer/2024_Gazetteer/2024_Gaz_place_national.zip"
LAND_URL = "https://raw.githubusercontent.com/nvkelso/natural-earth-vector/master/geojson/ne_110m_land.geojson"
OUT = os.path.join(os.path.dirname(os.path.abspath(__file__)), "..", "geo", "src", "commonMain", "composeResources", "files")

# Gazetteer NAME carries the legal/statistical area description as a trailing word or two.
LSAD = re.compile(r"\s+(city and borough|consolidated government|metropolitan government|unified government|"
                  r"urban county|municipality|borough|city|town|township|village|CDP|comunidad|zona urbana)$", re.I)

def fetch(url, scratch):
    path = os.path.join(scratch, os.path.basename(url))
    if not os.path.exists(path):
        urllib.request.urlretrieve(url, path)
    return path

def places(scratch):
    with zipfile.ZipFile(fetch(GAZ_URL, scratch)) as z:
        name = next(n for n in z.namelist() if n.endswith(".txt"))
        text = z.read(name).decode("latin-1")
    lines = text.splitlines()
    header = [h.strip() for h in lines[0].split("\t")]
    i_usps, i_name = header.index("USPS"), header.index("NAME")
    i_lat, i_lng = header.index("INTPTLAT"), header.index("INTPTLONG")
    best = {}  # key -> (land-area proxy unused; first wins after sort by population-free stable order)
    for line in lines[1:]:
        cols = [c.strip() for c in line.split("\t")]
        if len(cols) <= max(i_usps, i_name, i_lat, i_lng):
            continue
        city = LSAD.sub("", cols[i_name]).upper()
        city = re.sub(r"\s+", " ", city).strip()
        key = f"{city}, {cols[i_usps]}"
        if key not in best:
            best[key] = (float(cols[i_lat]), float(cols[i_lng]))
    return best

def write_places(table):
    buf = io.BytesIO()
    buf.write(b"SHPL"); buf.write(struct.pack(">ii", 1, len(table)))
    for key in sorted(table, key=lambda k: k.encode("utf-8")):
        kb = key.encode("utf-8"); lat, lng = table[key]
        buf.write(struct.pack(">H", len(kb))); buf.write(kb); buf.write(struct.pack(">ff", lat, lng))
    return buf.getvalue()

def write_land(scratch):
    with open(fetch(LAND_URL, scratch)) as f:
        gj = json.load(f)
    rings = []
    for feat in gj["features"]:
        g = feat["geometry"]
        polys = [g["coordinates"]] if g["type"] == "Polygon" else g["coordinates"]
        for poly in polys:
            rings.append(poly[0])  # outer ring only; 110m land has no lakes worth cutting out
    buf = io.BytesIO()
    buf.write(b"SHLD"); buf.write(struct.pack(">ii", 1, len(rings)))
    for ring in rings:
        buf.write(struct.pack(">i", len(ring)))
        for lng, lat in ring:
            buf.write(struct.pack(">ff", lng, lat))
    return buf.getvalue()

def main():
    if len(sys.argv) != 2:
        sys.exit(__doc__)
    scratch = sys.argv[1]
    os.makedirs(scratch, exist_ok=True); os.makedirs(OUT, exist_ok=True)
    table = places(scratch)
    with open(os.path.join(OUT, "places.bin"), "wb") as f: f.write(write_places(table))
    with open(os.path.join(OUT, "land110m.bin"), "wb") as f: f.write(write_land(scratch))
    print(f"places: {len(table)} keys; wrote {OUT}")

if __name__ == "__main__":
    main()
```

```kotlin
import android.content.Context
import android.location.Address
import android.os.Build
import kotlinx.coroutines.Dispatchers
import kotlinx.coroutines.suspendCancellableCoroutine
import kotlinx.coroutines.withContext
import java.util.Locale
import kotlin.coroutines.resume
import android.location.Geocoder as SystemGeocoder

class AndroidGeocoder(context: Context) : Geocoder {
    private val system = SystemGeocoder(context.applicationContext, Locale.US)

    override suspend fun lookup(key: String): GeoResult {
        if (!SystemGeocoder.isPresent()) return GeoResult.Unavailable
        return try {
            val first = if (Build.VERSION.SDK_INT >= 33) query33(key) else queryLegacy(key)
            first?.let { GeoResult.Found(LatLng(it.latitude, it.longitude)) } ?: GeoResult.NotFound
        } catch (e: java.io.IOException) {
            GeoResult.Unavailable  // offline or the backing service is down
        } catch (e: IllegalArgumentException) {
            GeoResult.NotFound
        }
    }

    private suspend fun query33(key: String): Address? = suspendCancellableCoroutine<Result<Address?>> { cont ->
        system.getFromLocationName(key, 1, object : SystemGeocoder.GeocodeListener {
            override fun onGeocode(addresses: MutableList<Address>) { cont.resume(Result.success(addresses.firstOrNull())) }
            override fun onError(errorMessage: String?) { cont.resume(Result.failure(java.io.IOException(errorMessage))) }
        })
    }.getOrThrow()

    @Suppress("DEPRECATION")
    private suspend fun queryLegacy(key: String): Address? = withContext(Dispatchers.IO) {
        system.getFromLocationName(key, 1)?.firstOrNull()
    }
}
```

```kotlin
                } ?: GeoResult.NotFound
            }
            if (cont.isActive) cont.resume(result)
```

```kotlin
// geo/src/commonMain/kotlin/com/dgmltn/shiphappens/geo/Route.kt
package com.dgmltn.shiphappens.geo

import com.dgmltn.shiphappens.domain.TrackingEvent

data class RouteStop(
    val key: String,
    val displayName: String,
    val at: LatLng,
    /** Oldest first. */
    val events: List<TrackingEvent>,
)

/**
 * Carriers log several scans per hub (arrived, departed, processed), so consecutive scans at
 * one place are one stop. A later return to the same hub is a separate stop — the route really
 * did double back. Scans with no usable location don't break a stop apart.
 */
fun buildRoute(events: List<TrackingEvent>, coords: Map<String, LatLng>): List<RouteStop> {
    val stops = ArrayList<RouteStop>()
    for (e in events.sortedBy { it.timestamp }) {
        val key = PlaceKey.normalize(e.location) ?: continue
        val at = coords[key] ?: continue
        val last = stops.lastOrNull()
        if (last != null && last.key == key) {
            stops[stops.lastIndex] = last.copy(events = last.events + e)
        } else {
            stops += RouteStop(key, displayPlace(e.location!!), at, listOf(e))
        }
    }
    return stops
}

fun displayPlace(raw: String): String {
    val key = PlaceKey.normalize(raw) ?: return raw.trim()
    return key.split(", ").joinToString(", ") { part ->
        if (part.length == 2 && part.all(Char::isLetter)) part
        else part.lowercase().split(' ').joinToString(" ") { w -> w.replaceFirstChar(Char::titlecase) }
    }
}
```

**Interfaces:**

- Produces:

Projection: equirectangular with longitude scaled by `cos(midLat)`. In "scaled degrees" a point is `(lng * k, lat)` with `k = cos(midLat in radians)`; aspect expansion happens in scaled space.

```kotlin
// geo/src/commonMain/kotlin/com/dgmltn/shiphappens/geo/Projection.kt
package com.dgmltn.shiphappens.geo

import kotlin.math.PI
import kotlin.math.cos

data class GeoBounds(
    val minLat: Double, val maxLat: Double,
    val minLng: Double, val maxLng: Double,
    /** Longitudes west of Greenwich were moved +360 so a Pacific crossing stays contiguous. */
    val shifted: Boolean,
) {
    val midLat: Double get() = (minLat + maxLat) / 2
}

fun GeoBounds.adjustLng(lng: Double): Double = if (shifted && lng < 0) lng + 360 else lng

private fun lngScale(midLat: Double) = cos(midLat * PI / 180.0).coerceAtLeast(0.2)

fun routeBounds(points: List<LatLng>, aspect: Double, padFraction: Double = 0.15, minSpanDeg: Double = 3.0): GeoBounds? {
    if (points.isEmpty()) return null
    val rawMin = points.minOf { it.lng }
    val rawMax = points.maxOf { it.lng }
    val shifted = rawMax - rawMin > 180.0
    val lngs = points.map { if (shifted && it.lng < 0) it.lng + 360 else it.lng }

    var minLat = points.minOf { it.lat }; var maxLat = points.maxOf { it.lat }
    var minLng = lngs.min(); var maxLng = lngs.max()

    fun widen(lo: Double, hi: Double, span: Double): Pair<Double, Double> {
        val mid = (lo + hi) / 2
        return (mid - span / 2) to (mid + span / 2)
    }

    val padLat = (maxLat - minLat) * padFraction
    val padLng = (maxLng - minLng) * padFraction
    minLat -= padLat; maxLat += padLat; minLng -= padLng; maxLng += padLng
    if (maxLat - minLat < minSpanDeg) widen(minLat, maxLat, minSpanDeg).let { minLat = it.first; maxLat = it.second }
    if (maxLng - minLng < minSpanDeg) widen(minLng, maxLng, minSpanDeg).let { minLng = it.first; maxLng = it.second }

    // Match the drawing area's aspect in scaled space so the map isn't stretched.
    val k = lngScale((minLat + maxLat) / 2)
    val scaledW = (maxLng - minLng) * k
    val h = maxLat - minLat
    if (scaledW / h < aspect) {
        widen(minLng, maxLng, aspect * h / k).let { minLng = it.first; maxLng = it.second }
    } else {
        widen(minLat, maxLat, scaledW / aspect).let { minLat = it.first; maxLat = it.second }
    }
    return GeoBounds(minLat, maxLat, minLng, maxLng, shifted)
}

class Projector(private val bounds: GeoBounds, private val width: Float, private val height: Float) {
    fun x(lng: Double): Float =
        ((bounds.adjustLng(lng) - bounds.minLng) / (bounds.maxLng - bounds.minLng) * width).toFloat()

    fun y(lat: Double): Float =
        ((bounds.maxLat - lat) / (bounds.maxLat - bounds.minLat) * height).toFloat()
}
```

Note: widening latitude for aspect changes `midLat`, which changes `k` slightly; the aspect test uses the *final* bounds' midLat, so compute `k` once from the pre-aspect midLat and accept the tiny drift — if the 1e-6 assertion fails, loosen it to 1e-2 rather than iterate (visual effect is nil).

```kotlin
// data/src/commonMain/kotlin/com/dgmltn/shiphappens/data/geo/GeoRepository.kt
package com.dgmltn.shiphappens.data.geo

import com.dgmltn.shiphappens.data.AppClock
import com.dgmltn.shiphappens.data.db.GeoCacheEntity
import com.dgmltn.shiphappens.data.db.GeoDao
import com.dgmltn.shiphappens.geo.GeoResult
import com.dgmltn.shiphappens.geo.Geocoder
import com.dgmltn.shiphappens.geo.LatLng
import com.dgmltn.shiphappens.geo.PlaceKey
import kotlinx.coroutines.flow.Flow
import kotlinx.coroutines.flow.channelFlow
import kotlinx.coroutines.flow.collect
import kotlinx.coroutines.flow.distinctUntilChanged
import kotlinx.coroutines.flow.flowOf
import kotlinx.coroutines.flow.map
import kotlinx.coroutines.launch
import kotlin.time.Duration.Companion.days

/**
 * Coordinates for carrier place names, remembered across parcels (hubs repeat constantly).
 * Resolution happens only while someone collects [observe] — i.e. while a detail screen is
 * open — so background refresh never spends geocoder quota.
 */
class GeoRepository(
    private val dao: GeoDao,
    private val bundled: Geocoder,
    private val platform: Geocoder,
    private val clock: AppClock,
) {
    fun observe(places: List<String>): Flow<Map<String, LatLng>> {
        val keys = places.mapNotNull(PlaceKey::normalize).distinct()
        if (keys.isEmpty()) return flowOf(emptyMap())
        return channelFlow {
            launch { resolveKeys(keys) }
            dao.observe(keys)
                .map { rows -> rows.mapNotNull { r -> if (r.lat != null && r.lng != null) r.key to LatLng(r.lat, r.lng) else null }.toMap() }
                .distinctUntilChanged()
                .collect { send(it) }
        }
    }

    internal suspend fun resolve(places: List<String>) = resolveKeys(places.mapNotNull(PlaceKey::normalize).distinct())

    private suspend fun resolveKeys(keys: List<String>) {
        val now = clock.now().toEpochMilliseconds()
        val cached = dao.get(keys).associateBy { it.key }
        var platformBudget = MAX_PLATFORM_LOOKUPS
        for (k in keys) {
            val row = cached[k]
            val stale = row == null || (row.lat == null && now - row.resolvedAt > MISS_TTL_MS)
            if (!stale) continue
            val local = bundled.lookup(k)
            if (local is GeoResult.Found && local.at.isValid) {
                dao.upsert(GeoCacheEntity(k, local.at.lat, local.at.lng, now)); continue
            }
            if (platformBudget == 0) continue  // the rest resolve next time the screen opens
            platformBudget--
            when (val r = platform.lookup(k)) {
                is GeoResult.Found ->
                    dao.upsert(if (r.at.isValid) GeoCacheEntity(k, r.at.lat, r.at.lng, now) else GeoCacheEntity(k, null, null, now))
                GeoResult.NotFound -> dao.upsert(GeoCacheEntity(k, null, null, now))
                GeoResult.Unavailable -> Unit  // offline or throttled: ask again next time
            }
        }
    }

    companion object {
        private val MISS_TTL_MS = 30.days.inWholeMilliseconds
        private const val MAX_PLATFORM_LOOKUPS = 10
    }
}
```

```kotlin
@Composable
fun RouteMap(route: RouteUi, accent: Color, locationText: String?, modifier: Modifier = Modifier) {
    var land by remember { mutableStateOf(LandOutline.EMPTY) }
    LaunchedEffect(Unit) { land = GeoAssets.land() }

    Box(modifier.fillMaxSize().semantics { contentDescription = route.description }) {
        Canvas(Modifier.fillMaxSize()) {
            val bounds = routeBounds(route.stops.map { it.at }, aspect = (size.width / size.height).toDouble())
                ?: return@Canvas
            val p = Projector(bounds, size.width, size.height)
            drawLand(land, p, bounds)
            drawRoute(route, p, accent)
        }
        locationText?.let {
            Text(it, color = ShipColors.muted, fontSize = 10.sp, fontFamily = monoFamily(),
                modifier = Modifier.align(Alignment.BottomStart).padding(12.dp)
                    .clip(RoundedCornerShape(6.dp)).background(Color.White.copy(alpha = .72f))
                    .padding(horizontal = 7.dp, vertical = 3.dp))
        }
    }
}

private fun DrawScope.drawLand(land: LandOutline, p: Projector, b: GeoBounds) {
    val path = Path()
    for (ring in land.rings) {
        if (ring.size < 6 || !ringTouches(ring, b)) continue
        path.moveTo(p.x(ring[0].toDouble()), p.y(ring[1].toDouble()))
        var i = 2
        while (i < ring.size) { path.lineTo(p.x(ring[i].toDouble()), p.y(ring[i + 1].toDouble())); i += 2 }
        path.close()
    }
    drawPath(path, LandColor)
}

/** Cheap cull: skip rings whose bbox misses the view (after the antimeridian shift). */
private fun ringTouches(ring: FloatArray, b: GeoBounds): Boolean {
    var minLng = Double.MAX_VALUE; var maxLng = -Double.MAX_VALUE
    var minLat = Double.MAX_VALUE; var maxLat = -Double.MAX_VALUE
    var i = 0
    while (i < ring.size) {
        val lng = b.adjustLng(ring[i].toDouble()); val lat = ring[i + 1].toDouble()
        if (lng < minLng) minLng = lng; if (lng > maxLng) maxLng = lng
        if (lat < minLat) minLat = lat; if (lat > maxLat) maxLat = lat
        i += 2
    }
    return maxLng >= b.minLng && minLng <= b.maxLng && maxLat >= b.minLat && minLat <= b.maxLat
}

internal fun DrawScope.drawRoute(route: RouteUi, p: Projector, accent: Color, selected: Int? = null) {
    val pts = route.stops.map { Offset(p.x(it.at.lng), p.y(it.at.lat)) }
    if (pts.size > 1) {
        val line = Path().apply { moveTo(pts[0].x, pts[0].y); pts.drop(1).forEach { lineTo(it.x, it.y) } }
        drawPath(line, accent, style = Stroke(width = 2.5.dp.toPx(), cap = StrokeCap.Round, join = StrokeJoin.Round))
    }
    pts.forEachIndexed { i, o ->
        val last = i == pts.lastIndex
        when {
            last -> {
                drawCircle(accent, radius = 7.dp.toPx(), center = o)
                if (route.delivered) drawCheck(o)
            }
            i == 0 -> {
                drawCircle(Color.White, radius = 5.dp.toPx(), center = o)
                drawCircle(accent, radius = 5.dp.toPx(), center = o, style = Stroke(2.dp.toPx()))
            }
            else -> drawCircle(accent, radius = 3.5.dp.toPx(), center = o)
        }
        if (i == selected) drawCircle(accent.copy(alpha = .35f), radius = 11.dp.toPx(), center = o, style = Stroke(3.dp.toPx()))
    }
}

private fun DrawScope.drawCheck(c: Offset) {
    val s = 3.dp.toPx()
    val check = Path().apply { moveTo(c.x - s, c.y); lineTo(c.x - s * .2f, c.y + s * .8f); lineTo(c.x + s * 1.1f, c.y - s * .9f) }
    drawPath(check, Color.White, style = Stroke(1.6.dp.toPx(), cap = StrokeCap.Round, join = StrokeJoin.Round))
}
```

```kotlin
package com.dgmltn.shiphappens.ui.detail

import androidx.compose.ui.geometry.Offset

internal fun nearestStop(points: List<Offset>, tap: Offset, radiusPx: Float): Int? {
    var best: Int? = null
    var bestD = radiusPx * radiusPx
    for (i in points.indices) {
        val d = (points[i] - tap).getDistanceSquared()
        if (d <= bestD) { best = i; bestD = d }
    }
    return best
}

internal fun nextSelection(current: Int?, hit: Int?): Int? = if (hit == null || hit == current) null else hit

internal fun selectionFor(previousStops: List<StopUi>, previous: Int?, stops: List<StopUi>): Int? =
    if (stops == previousStops && previous != null && previous in stops.indices) previous else null

internal fun calloutLines(stop: StopUi, max: Int = 4): List<String> {
    val lines = stop.events.take(max).map { "${it.whenText} · ${it.description}" }
    val more = stop.events.size - max
    return if (more > 0) lines + "+$more more" else lines
}
```
